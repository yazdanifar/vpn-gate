# UI specification (derived from the SwiftUI app)

Reference for the native Windows (WinUI 3), Linux (GTK4) and Android (Compose) UIs. Source of truth is
`Sources/VPNGateMac/UI/*.swift` plus the bound `Model/` types; citations are `file:line` at the time of writing
(2026-10-25) and will drift. Label strings are quoted as in the source and should be re-worded where they say "Mac"/"macOS".
Abbreviations: SL = ServerListView, AV = AccountsView, AE = AccountEditor, RS = RoutingSettingsView, ST = SettingsView,
FM = Formatting, M = Model/AppModel, AES = Model/AccountEditorState.

> There is **no statistics screen**. The only "statistics" feature is the opt-in Diagnostics upload (Settings → Advanced).
> Plan units U17b/U19/U23/U27 that mention "statistics" mean that upload plus traffic counters on the connection card.

## Global model
- Windows: main "VPN Gate Public VPN Relay Servers" (860x560 min), "VPN Connection Settings" (760x420), "Connection History"
  (720x380), "Connection Log" (720x420), Settings (560x480), and a menu-bar/tray extra.
- `ConnectionState` (IPCMessages.swift): disconnected, connecting, authenticating, dhcp, connected, reconnecting.
  Titles: "Disconnected", "Connecting…", "Authenticating…", "Getting address…", "Connected", "Reconnecting…".
  Icons: connected = locked shield, disconnected = open lock, anything else = spinning arrows.
- Live status is `HelperEvent` (`state, server, virtualIP, bytesIn, bytesOut, log, error, helperVersion`) plus
  `traffic` (bytes and speed in/out), `connectedAt`, `connectedServer` and `notice` (error/info string).
- `HelperRequest.cmd` is `connect | disconnect | status`; extra fields `host, port/ports, proxy, autoReconnect, blockIPv6,
  routing, tunnelMode, socksPort, config`.
- Formatters: speed "%.1f Mbps"; bytes binary units; rate = bytes + "/s"; duration "H:MM:SS". Traffic text is
  "↓ <in>  ↑ <out>"; with a start time it is prefixed by the duration and gets a second line "↓ <rate>  ↑ <rate>".

## 1. First-run disclaimer (modal, cannot be dismissed otherwise)
- Shown when the main window appears without consent, or when a connect is attempted before consent (the connect is parked and
  resumed on agree).
- Title "VPN Gate Academic Experiment Service". Body: "VPN Gate is an academic research project of the Graduate School of
  University of Tsukuba, Japan.\n\nPublic VPN relay servers are hosted by volunteers around the world. Anyone can connect
  through these servers to achieve anonymity and bypass censorship.\n\nBy clicking “Agree and Continue”, you confirm that you
  will use this service in compliance with local laws." Caption: "Optional diagnostics upload is off and can be turned on in
  Settings → Advanced."
- Buttons: "Disagree & Quit"; "Agree and Continue" (default, persists `hasAgreedToDisclaimer`, runs the parked action).

## 2. Tray / menu-bar menu
Icon = state symbol. Items in order: state title; server line ("<flag> <hostName> (<server>)" or the raw server);
"Virtual IP <ip>"; traffic text (connected only); divider; when disconnected "Connect to <hostName>" (last server or first
favorite, if any), otherwise "Disconnect" and "Reconnect" (if a last server exists); "Show VPN Gate"; "VPN Connection
Settings…"; "Settings…"; divider; "Quit".

## 3. Application menu commands
"Refresh List" (disabled while loading), "Disconnect" (disabled when disconnected), "Show VPN Gate", "Show VPN Connection
Settings", "Show Connection History", "Show Connection Log"; Help → "VPN Gate Web Site" (http://www.vpngate.net/).

## 4. Main window: server list
### Header and connection card
- Title "VPN Gate Public VPN Relay Servers"; intro "Gain freedom access to Internet by using VPN connection via Public VPN
  Servers provided by volunteers around the world. Bypass your local malfunctioning firewall's packet blocking, and hide your
  IP address safely."
- Card (top right, 260 wide; green when connected, grey when disconnected, orange otherwise): "Not connected" or the state
  title (spinner in transient states); "<flag> <hostName>"; "Virtual IP <ip>"; when connected a per-second traffic text with
  duration; when disconnected the red `notice` (3 lines max) else "Select a server and press Connect.".

### List status line
- Load error (red): "List update failed (<e>). Try again."
- Loading, empty list: "Refreshing the List… (about 1 MB, can take 10–20 s)"; loading, non-empty: "Refreshing the List…".
- Empty: "No servers yet. Press Refresh List."
- Normal: "<n> Public VPN Relay Servers on the Earth! (Updated at <date short>)" + " — showing <k>" when filtered; orange with
  "The list is old — press Refresh List." when over 24 h old. Tooltip "Source: <listSource>\nList generated by the server: <ts>".

### Toolbar
- Search "Search host, IP, country, operator" (ServerFilter).
- "Filter" menu: Country picker ("All countries" + sorted unique long names); Logging picker bound to `maxLogWeeks`
  ("Any logging policy" -1, "2 weeks or less" 2, "Up to 1 month" 5, "No logs only" 0); toggle "Favorites only"; "Clear Filters"
  (only when a filter is active). Icon filled when a filter is active.
- "Details" (disabled with no selection); "Test Connection" (tooltip: "Try a real VPN handshake with the listed servers and
  show the connect time from this Mac"); "Refresh List" (disabled while loading).

### Table
- Default sort Total Score descending; headers sort; columns reorderable/hideable, persisted (`listColumns.v1`).
- Default columns: "IP Address (Hostname)", "Region" ("<flag> <countryLong>"), "Uptime", "VPN Sessions", "Line Speed",
  "Ping (Google, SE)", "Test from this Mac", "Logging Policy", "Total Score".
- Hidden by default: "DDNS Hostname", "SSL-VPN (TCP)", "UDP Support", "Cumulative Transfers", "Cumulative Users",
  "Operator's Name" ("Anonymous" if empty), "Operator's Message".
- Probe cell: none "—" (tooltip "Not tested yet — press Test Connection"); queued "Waiting…"; testing spinner "Testing…";
  ok "<connectMs> ms" with a green check and caption "handshake <helloMs> ms · port <port>"; failed: red reason. Sort order

- Row menu: "Connect to the VPN Server" (disconnected only), "Server Details…", "Add to Favorites"/"Remove from Favorites".
  Double-click connects when disconnected.

### Bottom bar
- One button bound to state: disconnected → "Connect to the VPN Server" (default, disabled with no selection; tooltip "Select

### Server details sheet
Title "<flag> <hostName>" + "Done". Rows: "DDNS Hostname:", "IP Address:", "Country:" ("<long> (<short>)"), "Line Speed:",
"Score:", "Ping to Japan:", "Ping to Google:" ("-" if 0), "UDP port:", "SSL-VPN Ports:" ("Default (443)" if none), "OpenVPN UDP

### Helper setup / update alert
- Shown when the helper is missing or outdated. Title "One-time setup" (install) / "Update the VPN component?" (update).
  Message (macOS wording; re-word per OS): "VPN Gate needs a small background component to create the VPN connection. macOS

- Buttons "Continue" (starts setup; notice "Finish the installer, then VPN Gate connects automatically." or "Installer not

## 5. VPN Connection Settings window (accounts)
- Toolbar: "New Setting", "Connect" (needs a selection and disconnected), "Disconnect", "Properties", "Delete" (no confirmation).
- Pinned first row: "VPN Gate Public VPN Relay Servers" / "Free servers run by volunteers — open the list" (opens main).
- Orange `loadNotice` if present (e.g. damaged accounts file). Empty state: "No VPN connection settings yet" / "Add one to

- Columns: "VPN Connection Setting Name"; "Status" (Connected green / Connecting orange for connecting+authenticating+dhcp /

## 6. Account editor (sheet, min 480x520)
- Title "New VPN Connection Setting" / "Edit VPN Connection Setting".
- "General Setting": "Setting Name:" (default "New Connection").
- "Destination VPN Server": "Host Name / IP Address:", "Port Number (comma separated):" (default "443, 992, 5555, 1194"),
  "Virtual HUB Name:" (default "DEFAULT").
- "User Authentication Setting": "Auth Type:" = "Anonymous", "Standard Password (SHA-0)", "Plain Password", "User Certificate"
  (ticket not offered); "User Name:"; "Password:" (secure; password types only).
  - User Certificate: status text ("Certificate and RSA key ready to save." / "A certificate and key are stored in the
    Keychain. Import again to replace them." / "No certificate yet. Import a PEM/DER certificate with its RSA key, or a .p12
    file."); buttons "Certificate + Key (PEM/DER)…" (pickers "Choose the certificate (PEM or DER)" then "Choose its RSA
    private key (PEM or DER, not passphrase-protected)") and "PKCS#12 (.p12)…" ("Choose the PKCS#12 file (.p12 / .pfx)"); field
    "Passphrase for the .p12 file:"; red import error (EC keys and encrypted PEM keys are rejected).
- "Advanced Options" (collapsible): stepper "Max TCP Connections" (1–32, default 1); "Use Data Compression" (off); "Use UDP
  Acceleration (Fastest)" (on); "Use QoS" (on); "Use Half Connection (separate send/receive sockets)" (stored, ignored by the
  helper); "MTU (blank = automatic):" (error "MTU must be 576–1500, or blank for automatic."); "Virtual MAC address (blank =
  random):" (error "MAC must be 6 hex byte pairs, e.g. 00:AC:DE:12:34:56."); "Verify Server Certificate" (off); "Server
  certificate fingerprint (SHA-1 / SHA-256, optional):" (error "Fingerprint must be 40 (SHA-1) or 64 (SHA-256) hex digits.";
  help "A fingerprint is enforced whenever it is set. Without one, “Verify Server Certificate” uses the system trust store.");
  "Auto Reconnect on disconnect" (on) with "Retry every n s" (1–300, default 3) and "Give up after n attempts" (1–1000,
  default 8). If collapsed with an invalid field: "Something in the Advanced Options needs fixing before you can save."
- "Routing": toggle "Use custom routing rules for this connection"; off → "Uses the app's global routing rules (Settings →
  Routing)."; on → the routing editor (section 7).
- Buttons "Cancel" and "Save" (default). Save requires (`AES.canSave`): non-empty name and host; valid host (IPv4 literal or
  RFC 1123 hostname ≤253 chars, ASCII letters/digits/-/., no leading/trailing "-" or ".", no ".."; an all-digit-dot string must
  be a valid IPv4); valid fingerprint, MTU and MAC; certificate ready; hub and username ≤255 UTF-8 bytes with no NUL.
- Normalisation on save: ports parsed as UInt16 > 0 (none valid → [443]); empty hub → "DEFAULT"; empty MTU/MAC → nil;
  fingerprint normalised; `routing` nil unless custom routing is on. Password saved only if non-empty; cert/key only for the
  certificate type; secrets go to the platform secret store.

## 7. Routing rules editor (reusable: Settings and account editor)
- "Unmatched traffic": picker "By default" = "Proxy (through the tunnel)" / "Direct (bypass the tunnel)"; toggle "Bypass private
  networks (LAN, link-local, CGNAT)" (adds low-priority Direct rules for 10/8, 172.16/12, 192.168/16, 169.254/16, 127/8,
  100.64/10, fc00::/7, fe80::/10, ::1/128). Captions: Proxy → "Everything goes through the tunnel except what the rules below
  send elsewhere."; Direct → "Everything bypasses the tunnel except what the rules below send into it. IPv6 keeps being
  captured and dropped regardless (see “Block IPv6” in General)."
- "Rules": empty text "No custom rules. Traffic follows the default action above."; rows show the value (monospace), the
  type caption and an action pill (Proxy blue, Direct green, Block red) plus "Off" when disabled; tap to edit, drag to reorder,
  delete; button "Add Rule…".
- Footer: "Rules are checked in order from top to bottom; the first one that matches wins. Domain rules need the DNS proxy, which
  only runs while one is configured. A domain marked “Direct” is looked up through your regular network connection, never
  through the VPN or its DNS — everything else is resolved only through the tunnel."
- Rule sheet: "Match" = "Domain suffix" (default), "Domain (exact)", "Domain keyword", "Domain regex", "IP address", "IP range
  (CIDR)"; value placeholder per type (example.com / example.com / ads / ^(.+\.)?example\.com$ / 203.0.113.5 / 10.0.0.0/8);
  "Action" = Proxy (default)/Direct/Block; toggle "Enabled"; buttons "Delete" (edit only), "Cancel", "Add"/"Save" (disabled
  while invalid).
- Validation (shown only for a non-empty value): empty "Value is required."; suffix/exact "Not a valid domain name."
  (ASCII alnum/-/., ≤253, no leading/trailing ".", no ".."); keyword any non-empty; regex "Not a valid regular expression.";
  IP "Not a valid IPv4 or IPv6 address."; CIDR "A CIDR needs a /prefix, e.g. 10.0.0.0/8." (no "/") else "Not a valid CIDR range.".
- Semantics: first enabled match wins; the config is sent as `HelperRequest.routing`. Regex flavour: see U06 (NSRegularExpression
  vs the Rust `regex` crate may differ; the golden vectors must pin the supported subset).

- "VPN component": Status "Running" / "Installed, not running" / "Not installed"; buttons "Reinstall…"/"Install…" and

## 9. Connection History
Header "Connection history" + "Clear" (disabled when empty); empty text "No connections yet."; columns "Server", "Address",
"Connected" (month/day/hour/minute), "Duration" ("H:MM:SS" or "active"), "Traffic" ("↓ in  ↑ out"), "Result" (error in red;
"ended" if finished cleanly; blank while active). Stored locally, newest first, max 100 entries, one entry per connected
period.

## 10. Connection Log
Monospaced selectable text of the last 300 lines, auto-scrolling; toolbar "Copy" (disabled when empty). Lines come from
`HelperEvent.log` and "Error: <err>" when `HelperEvent.error` is set.

## 11. Behaviours to replicate
- List-initiated connections auto-reconnect forever every 15 s ("Reconnecting…"); account connections use the daemon's own
  retry count and interval.
- The helper status is polled every 2 s. The disclaimer is required before every connect path.

## Platform-specific items
- macOS-only UI: menu-bar extra, Settings scene, Cmd shortcuts, column customization, open panels, pasteboard, SF Symbols.
  Map to a tray icon, a preferences dialog, native menus, native file pickers and clipboard, and native icons.
- Privileged component: install/uninstall texts are macOS-specific. Replace with UAC + Windows Service (Windows), polkit +
  systemd (Linux). On Android there is no helper: hide "VPN component", use VpnService consent instead.
- Launch at login: Run key / startup task (Windows), XDG autostart (Linux); not applicable on Android.
- Secrets: Credential Manager (Windows), libsecret (Linux), Android Keystore.
- Wording: strings containing "Mac"/"macOS" ("Full tunnel (whole Mac)", "Test from this Mac", the Diagnostics header, the
  setup message) must be re-worded per OS.
- Certificate import: PKCS#12 parsing on mac uses the Security framework; each port needs its own PKCS#12 parser (or delegate
  it to the Rust engine). Only RSA keys (PKCS#1/PKCS#8) without a passphrase are supported in PEM/DER form.
- Android: SOCKS5-only mode is an open question (see U27); routing rules map to `excludeRoute`/route splitting.
